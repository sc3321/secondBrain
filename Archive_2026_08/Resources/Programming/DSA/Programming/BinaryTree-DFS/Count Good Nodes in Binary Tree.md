The main problem in this question is keeping track of the idea of the max. This is something which in general can be quite difficult in recursion, keeping track of a max variable. In general if this is something that needs to be done, a separate function may have to be created as in this example. Max is passed in as a secondary parameter and will be used to keep track of the largest value in the path so far. This is a useful technique so please remember to use it as necessary in other recursive problems.
