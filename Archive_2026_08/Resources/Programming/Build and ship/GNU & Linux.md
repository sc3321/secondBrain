-  UNIX is the original OS. Some core UNIX design ideas include:
	- Hierarchical file system.
	- Universal portability because it was written in C.
	- Module programs that do certain things really well. 
	- Text based software.
- Linux:
	- Kernel only.
- GNU:
	- Free utility tools compatible with the UNIX OS.
	- These include things like compilers, bash, utility tools etc.

Modern distributions are Linux + GNU.
