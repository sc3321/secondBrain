This problem follows some standard recursive behaviour, namely the dfs search, the hardest part was formulating the dfs nature of the problem but it becomes obvious once shown. The idea is to keep traversing nodes that are connected from each row. ￼￼start at row 0 and do a dfs search for every element on row 0.￼lets say [0][1] is 0 but [0][2] [0][3] are 1. When we hit [0][2] in the for loop of the main function we call the DFS helper function on that element. We then search through every single element on row [2][i]. The moment we traverse this row if no other 1s are found then we go back and do the dfs again on [0][3]. The keeps going and on each iteration we add traversed rows to our list of visitted provinces.￼￼The main C++ related concept here is "Passing by reference":￼￼In the line set\<int\>& visitted in the dfs declaration, the & ensures we are passing by reference. This means that we are passing the address of a set so each function call will modify the same set in memory. Otherwise each function call will modify its own private copy of the set variable which is inefficient and incorrect logic. The & also ensures that we can do forward declarations as it tells the compiler that this data type simply exists and that it can be handled later. In situations without using the necessary # include headers, this is critical.
